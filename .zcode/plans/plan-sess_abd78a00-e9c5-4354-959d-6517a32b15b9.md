# План: нативное iOS-приложение (SwiftUI + PencilKit + Pencil Pro)

## Что делаем

Полноценное нативное приложение **PaintByNumbers** для iPad (Swift/SwiftUI), устанавливаемое на устройство: импорт фото → умный конвейер → раскрашивание Pencil с полной интеграцией Pencil Pro → каталог проектов с прогрессом → экспорт. Веб-версия остаётся в репо без изменений, нативное приложение живёт в `ios/`.

## Структура поставки

```
ios/
├── project.yml                      # XcodeGen-спека проекта (pbxproj не пишем руками)
├── PaintByNumbers/                  # апп-таргет (SwiftUI, iOS 17.5+)
│   ├── App/ (точка входа, роутинг экранов)
│   ├── Screens/ Home, Processing, Coloring, Catalog
│   ├── Canvas/ ColoringCanvasView (PKCanvasView-обёртка, слои, зум)
│   ├── Palette/, Export/, Store/ (проекты + прогресс, Codable в Documents)
│   └── Resources/ (Assets: AppIcon из существующего icon-512, ru/en Localizable)
└── PaintEngine/                     # локальный Swift Package: ВЕСЬ алгоритмический порт
    ├── Sources/ (colorSpace, quantize, slic, smooth, segment, vectorize, labels, pipeline, fillRender)
    └── Tests/ (XCTest: порт существующих тестов + новые CIEDE2000/контраст-слияние/medoid)
.github/workflows/ios.yml           # macOS-раннер: xcodegen → xcodebuild build+test → unsigned IPA
README-IOS.md                       # установка на iPad без Mac (AltStore/Sideloadly с Windows)
```

## A. Движок (порт на Swift, чистый Foundation — тестируем где угодно)

Порт конвейера v3 + все правки качества из вашего анализа: CIEDE2000 (эталонные пары Sharma в тестах), **контраст-осознанное слияние** (не сливать при ΔE00 ≥ 12 — губы/люверсы выживают), **medoid вместо среднего** для цветов палитры, **авто-k floor** (мин. k, где ≥90% пикселей имеют ΔE00 ≤ 10), majority-фильтр ×2, guided filter мягче (r=3, eps=80), векторные контуры (границы→Дуглас-Пекер→Чайкин). Реализация на DispatchQueues с колбэками прогресса.

**Локальная проверка:** попробую поставить Swift-тулчейн на Windows (`swift test` работает для Foundation-пакета) — если не выйдет, тесты прогонит CI.

## B. Рисование — PencilKit + Pencil Pro (всё, что даёт натив)

- **PKCanvasView**: перо с давлением/наклоном/**Barrel Roll** (PencilKit учитывает roll в каллиграфических перьях сам), ластик стирает только краску (контуры — отдельный CALayer под холстом), undo через системный UndoManager, зум — UIScrollView (pinch/pan, как в веб-версии).
- **Squeeze (Pencil Pro, iOS 17.5)**: `UIPencilInteraction` → всплывающая палитра у кончика пера + тактильный отклик.
- **Двойное касание**: переключение кисть↔ластик (настраиваемо).
- **Hover**: `UIHoverGestureRecognizer` — кольцо-курсор кисти до касания.
- **Haptics**: `UIImpactFeedbackGenerator`/`UISelectionFeedbackGenerator` на выбор цвета, undo, заливку.
- **Palm rejection**: политика ввода «только Pencil» (переключатель в настройках), ладонь не рисует никогда.
- Прогресс: рендер `PKDrawing` в изображение → проход по `labels` → % закрашенного и завершённые регионы.

## C. Приложение

- **Home**: фото-импорт (PhotosPicker) + продолженные проекты.
- **Каталог**: сетка карточек — миниатюра, имя, дата, число цветов, кольцо прогресса; открытие/удаление. Прогресс хранится в проекте, у каждого пользователя — свой (песочница приложения изолирована по умолчанию).
- **Coloring**: слои (фон → контуры+номера → подсветка активного цвета → PencilKit-краска), палитра с номерами и свободными цветами, «Закончить за меня», экспорт PNG/JPEG с легендой → Поделиться/Сохранить в Фото.
- Локализация ru/en, iPad-адаптивность (safe areas, две колонки каталога в ландшафте).

## D. Сборка и установка без Mac

1. **GitHub Actions** (`macos-15`): XcodeGen генерирует проект → `xcodebuild build` + `xcodebuild test` на симуляторе iOS 18 → сборка **unsigned IPA** артефактом.
2. **Установка на iPad с Windows**: AltServer (Windows) + AltStore, или Sideloadly — подпись бесплатным Apple ID (7 дней, потом переподпись одним кликом). Инструкция в README-IOS.md.
3. Проверка: если `gh` авторизован — создаю репо, пушу, **сам гоняю CI и чиню ошибки компиляции по логам** до зелёного билда. Первая компиляция Swift-кода произойдёт в CI; ожидаю 1-2 итерации правок API.

## E. Тесты

- XCTest в PaintEngine: порты colorSpace/quantize/segment/autoPalette/pipeline + новые CIEDE2000 (Sharma ±0.02), контраст-слияние, medoid, авто-k floor, подсчёт прогресса. CI гоняет их на симуляторе/маке при каждом пуше.
